# Документация компонента Dropdown

## 1. Описание компонента

`Dropdown` — это UI-компонент для сортировки списка задач. Компонент состоит из кнопки-триггера, которая отображает текущий выбранный вариант сортировки, и выпадающего списка с доступными вариантами сортировки.

**Назначение**: Позволяет пользователю выбирать способ сортировки задач в списке.

---

## 2. Функциональные требования

### 2.1. Базовое поведение

- **Состояние по умолчанию**:
  - Dropdown закрыт
  - Выбрана сортировка по дате создания, по убыванию (`createdAt-desc`) — новые задачи сверху
  - Кнопка отображает иконку направления + текст выбранной сортировки (например: "↓ Дате создания")

### 2.2. Открытие/закрытие

- **Открытие**:
  - При клике на кнопку-триггер список вариантов появляется
  - Анимация появления по `opacity` за `0.2s`
- **Закрытие происходит в трёх случаях**:
  1. Повторный клик на кнопку-триггер
  2. Выбор одного из вариантов сортировки
  3. Клик вне компонента (опционально, по аналогии с TaskEditor)

### 2.3. Выбор варианта сортировки

- При клике на вариант:
  1. Список задач пересортируется согласно выбранному критерию
  2. Dropdown закрывается
  3. Текст на кнопке-триггере обновляется на выбранный вариант

### 2.4. Обработка переполнения

- Если высота контента Dropdown превышает доступное пространство:
  - Контент обрезается (`overflow: hidden` или `overflow-y: auto`)
  - Адаптивная версия будет реализована позже

## 3. Технические требования

### 3.1. Структура файлов

### 3.2. Состояния компонента (state)

Компонент должен управлять следующими состояниями:

```javascript
const [isOpen, setIsOpen] = useState(false); // Открыт/закрыт
const [selectedSort, setSelectedSort] = useState({

  icon: 'arrowDown',
  field: 'createdAt',
  order: 'desc',
});
```

### 3.3. Варианты сортировки

**Важно**: Согласно макету, каждая сортировка имеет **два направления** (по возрастанию ↑ и по убыванию ↓).

**Структура данных для вариантов сортировки**:

```javascript
const sortOptions = [
  {
    value: 'priority-desc',
    label: 'Приоритету',
    icon: 'arrowDown',
    field: 'priority',
    order: 'desc',
  },
  {
    value: 'priority-asc',
    label: 'Приоритету',
    icon: 'arrowUp',
    field: 'priority',
    order: 'asc',
  },

  {
    value: 'title-desc',
    label: 'Алфавиту',
    icon: 'arrowDown',
    field: 'title',
    order: 'desc',
  },
  {
    value: 'title-asc',
    label: 'Алфавиту',
    icon: 'arrowUp',
    field: 'title',
    order: 'asc',
  },

  {
    value: 'createdAt-desc',
    label: 'Дате создания',
    icon: 'arrowDown',
    field: 'createdAt',
    order: 'desc',
  },
  {
    value: 'createdAt-asc',
    label: 'Дате создания',
    icon: 'arrowUp',
    field: 'createdAt',
    order: 'asc',
  },

  {
    value: 'updatedAt-desc',
    label: 'Дате обновления',
    icon: 'arrowDown',
    field: 'updatedAt',
    order: 'desc',
  },
  {
    value: 'updatedAt-asc',
    label: 'Дате обновления',
    icon: 'arrowUp',
    field: 'updatedAt',
    order: 'asc',
  },
];
```

**Пояснение полей**:

- `value` — уникальный идентификатор (формат: `поле-направление`)
- `label` — текст для отображения
- `icon` — иконка направления (`arrowDown` или `arrowUp`)
- `field` — поле для сортировки
- `order` — направление (`asc` — по возрастанию, `desc` — по убыванию)

**По умолчанию**: выбрана сортировка `'createdAt-desc'` (по дате создания, новые сверху)

### 3.4. Анимация

Анимация реализуется по аналогии с `TaskEditor`:

```css
.dropdown {
  opacity: 0;
  transition: opacity 0.2s ease-in-out;
  pointer-events: none;
}

.dropdownOpen {
  opacity: 1;
  pointer-events: auto;
}
```

**Принцип работы**:

- В закрытом состоянии: `opacity: 0` + `pointer-events: none`
- В открытом состоянии: `opacity: 1` + `pointer-events: auto`
- Переход занимает `0.2s`

## 4. Props компонента

### 4.1. Входные параметры (props)

```javascript
<Dropdown
  options={sortOptions} // Массив вариантов сортировки
  defaultValue='createdAt-desc' // Значение по умолчанию
  onSortChange={handleSortChange} // Коллбэк при изменении
  disabled={false} // Заблокирован/активен
/>
```

| Prop           | Тип                                         | Обязательный | Описание                                                 |
| -------------- | ------------------------------------------- | ------------ | -------------------------------------------------------- |
| `options`      | `Array<{value, label, icon, field, order}>` | Да           | Массив вариантов сортировки (см. раздел 3.3)             |
| `defaultValue` | `string`                                    | Нет          | Значение по умолчанию (по умолчанию: `'createdAt-desc'`) |
| `onSortChange` | `function(value: string)`                   | Да           | Функция, вызываемая при изменении сортировки             |
| `disabled`     | `boolean`                                   | Нет          | Блокирует компонент (по умолчанию: `false`)              |

### 4.2. Коллбэк onSortChange

Функция получает выбранное значение и должна:

1. Обновить сортировку в родительском компоненте
2. Пересортировать список задач

**Пример использования**:

```javascript
const handleSortChange = (sortValue) => {
  // Логика сортировки массива задач
  setSortedTasks(sortTasksBy(tasks, sortValue));
};
```

## 5. Структура компонента

### 5.1. Логическая структура

```
Dropdown
├── DropdownTrigger (кнопка)
│   └── Текст выбранного варианта + иконка стрелки
└── DropdownMenu (выпадающий список)
    └── DropdownItem (вариант сортировки) × N
```

### 5.2. Пример JSX-структуры

```jsx
<div className={styles.dropdown} ref={dropdownRef}>
  {/* Кнопка-триггер с иконкой направления + текст */}
  <button className={styles.dropdownTrigger} onClick={toggleDropdown}>
    <Icon name={selectedSort.icon} />
    <span>{selectedSort.label}</span>
  </button>

  {/* Выпадающий список вариантов */}
  <div className={`${styles.dropdownMenu} ${isOpen ? styles.dropdownMenuOpen : ''}`}>
    {options.map((option) => (
      <button
        key={option.value}
        className={`${styles.dropdownItem} ${
          selectedSort.value === option.value ? styles.dropdownItemSelected : ''
        }`}
        onClick={() => handleSelect(option)}>
        <Icon name={option.icon} />
        <span>{option.label}</span>
        {/* Галочка для выбранного элемента */}
        {selectedSort.value === option.value && <Icon name='check' className={styles.checkIcon} />}
      </button>
    ))}
  </div>
</div>
```

**Примечание**: В макете выбранный вариант отмечен галочкой справа.

## 6. Взаимодействие с другими компонентами

### 6.1. Интеграция в приложение

Компонент Dropdown должен быть размещён в том же контейнере, где находится список задач (вероятно, в `IncomingTasks` или подобном компоненте).

### 6.2. Связь с контекстом задач

Для управления сортировкой задач потребуется:

**Вариант 1: Локальное состояние** (если сортировка нужна только в одном месте)

```javascript
const [tasks, setTasks] = useState(initialTasks);
const [sortBy, setSortBy] = useState('createdAt-desc'); // Значение по умолчанию

const sortedTasks = useMemo(() => {
  return sortTasksBy(tasks, sortBy);
}, [tasks, sortBy]);
```

**Вариант 2: Глобальный контекст** (если сортировка нужна в разных местах)

- Добавить состояние `sortBy` в `TaskContext`
- Создать функцию `setSortBy` для изменения сортировки
- Возвращать уже отсортированный массив задач из контекста

**Рекомендация**: Для данного проекта локальное состояние будет достаточным.

### 7.1. Обязательные состояния

1. **`:hover`** — изменение фона/цвета при наведении на:

   - Кнопку-триггер
   - Элементы списка

   - Элементов списка (для навигации с клавиатуры)

3. **`:active`** — визуальная обратная связь при клике

4. **Выбранный элемент** — особый стиль для текущего выбранного варианта в списке

### 7.2. Переполнение контентом

```css
.dropdownMenu {
  max-height: 300px; /* Или другое значение */
  overflow-y: auto; /* Прокрутка, если не умещается */
}
```

### 7.3. Позиционирование

Dropdown-меню должно:

- Позиционироваться относительно кнопки-триггера (`position: absolute`)
- Открываться вниз (но можно предусмотреть открытие вверх, если места снизу мало)

```css

  position: relative;
}

.dropdownMenu {
  position: absolute;
  top: 100%; /* Прямо под кнопкой */
  left: 0;
  z-index: 10;
}
```

## 8. Расширение TaskEditor для редактирования

### 8.1. Новый режим работы

Компонент `TaskEditor` должен поддерживать два режима:

```javascript
<TaskEditor
  type="create"  // Режим создания (по умолчанию)
/>

<TaskEditor
  type="edit"    // Режим редактирования
  task={taskData} // Данные редактируемой задачи
/>
```

### 8.2. Props для режима редактирования

| Prop   | Тип                  | Описание                                    |
| ------ | -------------------- | ------------------------------------------- |
| `type` | `'create' \| 'edit'` | Режим работы компонента                     |
| `task` | `Object`             | Объект с данными задачи (для `type="edit"`) |

### 8.3. Структура объекта task

```javascript
{
  id: string,           // Неизменяемый ID задачи
  title: string,        // Заголовок задачи
  priority: number,     // Приоритет (1, 2, 3)
  createdAt: Date,      // Дата создания (неизменяемая)
  updatedAt: Date       // Дата изменения (обновляется при сохранении)
}
```

### 8.4. Логика работы кнопки "Сохранить"

**В режиме создания**:

- Кнопка активна, если поле `title` не пустое

**В режиме редактирования**:

- Кнопка активна, если:
  1. Поле `title` не пустое, **И**
  2. Хотя бы одно поле изменилось (сравнение с исходными данными)

### 8.5. Поведение кнопки "Удалить"

- Кнопка "Удалить" отображается **только в режиме редактирования**
- При клике:
  1. Задача удаляется из списка
  2. `TaskEditor` закрывается

### 8.6. Обработка отмены

**В режиме редактирования**:

- При нажатии "Отмена": все изменения отменяются, исходные данные остаются без изменений
- `TaskEditor` закрывается без сохранения

## 11. Реализация вариантов сортировки

### 11.1. Функция сортировки

Необходимо реализовать функцию, которая сортирует массив задач **с учётом направления**:

```javascript
/**
 * Сортирует массив задач
 * @param {Array} tasks - Массив задач
 * @param {string} sortValue - Значение сортировки в формате "поле-направление" (например: "priority-desc")
 * @returns {Array} - Отсортированный массив задач
 */
function sortTasksBy(tasks, sortValue) {
  const sortedTasks = [...tasks]; // Создаём копию массива

  // Разбираем значение: 'priority-desc' -> field='priority', order='desc'
  const [field, order] = sortValue.split('-');
  const isAscending = order === 'asc'; // true = по возрастанию, false = по убыванию

  switch (field) {
    case 'priority':
      // Сортировка по приоритету (числа)
      return sortedTasks.sort((a, b) =>
        isAscending ? a.priority - b.priority : b.priority - a.priority,
      );

    case 'title':
      // Сортировка по алфавиту (строки)
      return sortedTasks.sort((a, b) => {
        const result = a.title.localeCompare(b.title, 'ru');
        return isAscending ? result : -result;
      });

    case 'createdAt':
      // Сортировка по дате создания
      return sortedTasks.sort((a, b) => {
        const diff = new Date(a.createdAt) - new Date(b.createdAt);
        return isAscending ? diff : -diff;
      });

    case 'updatedAt':
      // Сортировка по дате обновления
      return sortedTasks.sort((a, b) => {
        const diff = new Date(a.updatedAt) - new Date(b.updatedAt);
        return isAscending ? diff : -diff;
      });

    default:
      return sortedTasks;
  }
}
```

**Пояснение логики**:

1. **Разбор значения**: `'priority-desc'.split('-')` → `['priority', 'desc']`
2. **Определение направления**: `order === 'asc'` → `true` (по возрастанию) или `false` (по убыванию)
3. **Применение направления**:
   - Для возрастания: результат как есть (`a - b`)
   - Для убывания: инвертируем результат (`b - a` или `-result`)

**Альтернативная реализация через объект**:

Можно также передавать в функцию объект целиком:

```javascript
function sortTasksBy(tasks, sortOption) {
  const { field, order } = sortOption;
  const sortedTasks = [...tasks];
  const isAscending = order === 'asc';

  // ... тот же switch
}

// Использование:
const sorted = sortTasksBy(tasks, selectedSort);
```

### 11.2. Варианты сортировки из макета

Согласно макету, реализованы **8 вариантов сортировки** (4 типа × 2 направления):

| Вариант           | Value            | Описание                                 | Иконка |
| ----------------- | ---------------- | ---------------------------------------- | ------ |
| Приоритету ↓      | `priority-desc`  | От высокого приоритета к низкому (3 → 1) | ↓      |
| Приоритету ↑      | `priority-asc`   | От низкого приоритета к высокому (1 → 3) | ↑      |
| Алфавиту ↓        | `title-desc`     | От Я к А (обратный алфавит)              | ↓      |
| Алфавиту ↑        | `title-asc`      | От А к Я (прямой алфавит)                | ↑      |
| Дате создания ↓   | `createdAt-desc` | Новые задачи сверху (по умолчанию)       | ↓      |
| Дате создания ↑   | `createdAt-asc`  | Старые задачи сверху                     | ↑      |
| Дате обновления ↓ | `updatedAt-desc` | Недавно изменённые сверху                | ↓      |
| Дате обновления ↑ | `updatedAt-asc`  | Давно изменённые сверху                  | ↑      |

**По умолчанию**: выбрана сортировка **"Дате создания ↓"** (`createdAt-desc`) — новые задачи отображаются сверху списка.

## 13. Примечания и рекомендации

### 13.1. Хуки, которые могут понадобиться

- `useState` — для управления состоянием (открыт/закрыт, выбранный вариант)
- `useRef` — для ссылки на DOM-элемент Dropdown
- `useClickOutside` — для закрытия при клике вне (можно переиспользовать из хуков)
- `useMemo` — для оптимизации сортировки (важно!)
- `useCallback` — для мемоизации обработчиков

### 13.1.1. Иконки, которые понадобятся

Для реализации Dropdown нужны следующие иконки:

- `arrowDown` (↓) — стрелка вниз, для сортировки по убыванию
- `arrowUp` (↑) — стрелка вверх, для сортировки по возрастанию
- `check` (✓) — галочка для отметки выбранного варианта

**Примечание**: Убедись, что эти иконки добавлены в папку `src/components/icon/icons/` и экспортированы в `index.js`.

### 13.2. Доступность (a11y)

Для улучшения доступности рекомендуется:

```jsx
<button
  aria-expanded={isOpen}
  aria-haspopup="listbox"
>
  {selectedSort.label}
</button>

<div role="listbox" aria-label="Варианты сортировки">
  {options.map((option) => (
    <button
      role="option"
      aria-selected={option.value === selectedSort.value}
    >
      {option.label}
    </button>
  ))}
</div>
```

### 13.3. Оптимизация
